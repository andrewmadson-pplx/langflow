<Icon name="Blocks" aria-hidden="true" /> [**Bundles**](/components-bundle-components) contain custom components that support specific third-party integrations with Langflow.

This page describes the components that are available in the **Perplexity** bundle.

For more information about Perplexity features and functionality used by Perplexity components, see the [Perplexity documentation](https://perplexity.ai/).

## Perplexity text generation

This component generates text using models on the [Perplexity Agent API](https://docs.perplexity.ai/docs/agent-api/models), such as `perplexity/sonar`, `openai/gpt-5.5`, and `anthropic/claude-sonnet-5-5`.

When **Web Search** is on, which is the default, each request makes Perplexity's `web_search` tool available to the model. The model decides when to search, and Perplexity bills each search separately from tokens. For more information, see [Perplexity pricing](https://docs.perplexity.ai/docs/getting-started/pricing). When an Agent binds its own tools to the **Language Model** output, the request carries those tools instead.

It can output either a **Model Response** ([`Message`](/data-types#message)) or a **Language Model** ([`LanguageModel`](/data-types#languagemodel)).

Use the **Language Model** output when you want to use a Perplexity model as the LLM for another LLM-driven component, such as an **Agent** or **Smart Transform** component.

For more information, see [Language model components](/components-models).

### Perplexity text generation parameters

<PartialParams />

| Name | Type | Description |
|------|------|-------------|
| model_name | String | Input parameter. The Agent API model to use. Choose from the list or enter any model ID from the Agent API model list. Default: `perplexity/sonar`. |
| max_tokens | Integer | Input parameter. The maximum number of tokens to generate. |
| api_key | SecretString | Input parameter. The Perplexity API Key for authentication. |
| web_search | Boolean | Input parameter. Whether the request makes Perplexity's `web_search` tool available to the model. Turn it off to send no tools. Default: `true`. |
| temperature | Float | Deprecated. Hidden and not sent to the Agent API. |
| top_p | Float | Deprecated. Hidden and not sent to the Agent API. |
| n | Integer | Deprecated. Hidden and not sent to the Agent API. |

A flow saved with one of the retired `llama-3.1-*` model IDs, or with the Sonar Chat Completions ID `sonar`, runs on `perplexity/sonar` after you update the component, and the component logs a message that names both models. Any other model ID is sent to the Agent API unchanged.
